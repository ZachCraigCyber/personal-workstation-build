# personal-workstation-build

## Custom Gaming PC Build – Personal Workstation

### Overview
Designed and assembled a custom gaming and productivity PC from individual components. Planned hardware selection, completed system assembly, configured firmware settings, and deployed the operating system.

### Responsibilities
- Researched and selected compatible hardware components.
- Assembled and wired the complete system.
- Configured BIOS settings and system firmware.
- Installed and configured Windows 11.
- Installed drivers, updates, and software.
- Troubleshot hardware and boot-related issues.
- Performed system validation and stability testing.

### Skills Demonstrated
- PC Assembly
- Hardware Troubleshooting
- BIOS Configuration
- Windows Administration
- System Integration
- Driver Installation

### Components
- CPU: AMD Ryzen 7 9800X3D 4.7 GHz 8-Core Processor
- CPU Cooler: NZXT Kraken Z73 RGB 52.44 CFM Liquid CPU Cooler
- GPU: Gigabyte Vision OC GeForce RTX 3070 Ti 8 GB Video Card
- Motherboard: Gigabyte X870 AORUS ELITE WIFI7 ICE ATX AM5 Motherboard
- RAM: Corsair Vengeance RGB 32 GB (2 x 16 GB) DDR5-6000 CL30 Memory
- Storage: Samsung 970 Evo Plus 2 TB M.2-2280 PCIe 3.0 X4 NVME Solid State Drive
- Power Supply: Corsair RM850 850 W 80+ Gold Certified Fully Modular ATX Power Supply
- Case: Lian Li O11 Dynamic EVO ATX Mid Tower Case
